# Participant agenda

## Before the workshop

- Install Claude Code and sign in.
- Clone this repository.
- Install Node.js 20 or newer for the local exercise checks.
- Confirm that `claude --version` and `node --version` run in your terminal.
- Use a sandbox or training account. The exercises do not need production credentials.

## Four-hour workshop

| Time | Module | Outcome |
|---|---|---|
| 00:00–00:12 | Welcome and show of hands | Shared baseline for AI use and risk tolerance |
| 00:12–00:30 | Adoption levels and Claude Code map | A vocabulary for delegation and extension mechanisms |
| 00:30–00:50 | Prompt contracts | One prompt with a measurable finish line |
| 00:50–01:20 | Skills: design, evaluation, and maintenance | A small skill with positive and negative trigger tests |
| 01:20–01:35 | Sharing skills | A decision between project skill, plugin, marketplace, and managed delivery |
| 01:35–01:50 | Break | |

## Working agreement

- Never use production credentials in the exercises.
- Treat model output as a proposal until a deterministic check confirms it.
- State which environment and commands were actually verified.
- Keep external side effects behind explicit human approval.
- Prefer small, reversible changes with visible evidence.
